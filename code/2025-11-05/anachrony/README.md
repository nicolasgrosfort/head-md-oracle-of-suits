# Anachrony

Using p5.js with typescript and vite.js.

## Initial setup

```bash
    yarn install
```

## Start the development server

```bash
    yarn dev
```

## Build for production

```bash
    yarn build
```

## Preview the production build

```bash
    yarn preview
```
