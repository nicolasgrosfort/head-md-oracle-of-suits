# Code

This folder contains code experiments for the `Oracle of Suits` project, with `Media Pipe` and `P5.js` libraries.
The aim of this workshop is to explore and design new ways of using the body moving in space as a controller.

## Folder Structure

- Each folder is named with the today's date `YYYY-MM-DD`.
- Each folder contains a `README.md` file explaining the experiment done that day.
- Each folder contains subfolders with the code experiments done that day, named with a short title of the experiment.
