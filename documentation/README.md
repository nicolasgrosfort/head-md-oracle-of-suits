# Documentation

## Structure

1. `Code`: poc, research, experiments and exploration.
2. `Concepts`: design ideas, prototypes, iterations.
3. `Gestures`: gesture library, detailed descriptions.
4. `Journal`: introspective notes, thoughts, feelings.
5. `Observations`: raw notes, ideas, readings, videos, exploration, etc.
6. `References`: more structured notes, concepts, ideas, vocabulary.
7. `Setup`: tools, files, or notes that help with project installation or documentation.

## Conventions

### Global

- One file per idea
- Use `#tag` to create links between ideas

### Texts

- Markdown format (.md)
- YYYY-MM-DD date format
- Filename follow the pattern: `[date]-[title?]-[version?].md`
- Example: `2025-10-01-hanafuda.md`

### Images

- In an `image` folder
- Filename follow the pattern: `[title]-[version?].md`
- Exemple: `hanafuda-1.png`
