# Process

## Structure

1. `Concepts`: design ideas, prototypes, iterations.
2. `Journal`: introspective notes, thoughts, feelings.
3. `Observations`: raw notes, ideas, readings, videos, exploration, etc.
4. `References`: more structured notes, concepts, ideas, vocabulary.

## Conventions

### Global

- One file per idea
- Use `#tag` to create links between ideas

### Texts

- Markdown format (.md)
- YYYY-MM-DD date format
- Filename follow the pattern: `[date]-[title?]-[version?].md`
- Example: `2025-10-01-hanafuda.md`

### Images

- In an `image` folder
- Filename follow the pattern: `[title]-[version?].md`
- Exemple: `hanafuda-1.png`
